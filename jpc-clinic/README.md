# jpc-clinic
React + Vite school clinic management app based on the provided Student Information System reference.

## Run
1. `npm install`
2. `npm run dev`

## Included
- Login with Basic/Higher Education selection
- Dashboard statistics
- Patient/student records with search and filters
- Add patient
- Vital signs recording (BP, HR, RR, temperature, SpO2)
- General clinic visits
- Medication dispensing records
- Simple reports and print button
- Profile page
- LocalStorage persistence so demo data remains after refresh
